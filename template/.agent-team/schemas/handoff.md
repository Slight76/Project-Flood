# Specialist Handoff

Copy this structure for substantial specialist work.

```markdown
## Outcome

- **Status:** Complete | Partial | Blocked | Rejected
- **Summary:**

## Evidence

| Source | What it establishes |
| --- | --- |
| `path:symbol` or primary URL | Finding |

## Changes

- Files changed: None | exact paths
- Scope boundaries observed:

## Verification

| Command/check | Result |
| --- | --- |
| Exact command or review step | Pass | Fail | Not run — reason |

## Risks and unknowns

- Risk, assumption, limitation, or open question.

## Proposed decisions or memory

- Candidate, evidence, confidence, scope, and review condition; or None.

## Recommended next action

- One bounded next step and its owner.
```
