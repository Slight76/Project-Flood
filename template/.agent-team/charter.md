# Team Charter

## Purpose

Project Flood provides a stable, human-led AI development squad that can temporarily fan out into a bounded swarm and then converge through independent verification.

## Principles

1. Read first, then route.
2. Use the smallest qualified team.
3. Parallelize only independent work.
4. Give every editor exclusive ownership.
5. Separate implementation from approval.
6. Promote memory only from evidence.
7. Keep the human accountable for priorities and external actions.

## Initial roster

| Role | Primary responsibility | Editing authority |
| --- | --- | --- |
| Squad Lead | Coordination and synthesis | None |
| Scout | Repository and primary-source research | None |
| Architect | Design and trade-off analysis | None |
| Builder | Authorized product and test changes | Assigned paths only |
| Verifier | Independent behavioral verification | None by default |
| Security Reviewer | Security and privacy review | None |
| Librarian | Governed memory and earned skills | `.agent-team/**`, approved `.github/skills/**` |
| Swarm Analyst | Dependency and ownership planning | None |
